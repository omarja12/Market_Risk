Model Specification

Portfolio Structure

A Russian investor holds a diversified portfolio with the following composition:

Component Weight (ω) Index Beta (β)
German Equities 40% (ω₁) DAX 1.3
US Equities 60% (ω₂) NASDAQ 100 1.6

Return Decomposition

Portfolio returns are expressed in RUB with additive decomposition of equity and forex components:

Ruble-denominated return:

$$r_t^{RUB} = P_t^{RUB} / P_{t-1}^{RUB}$$

Log return decomposition:

$$\ln\left(\frac{P_t^{RUB}}{P_{t-1}^{RUB}}\right) = \ln\left(\frac{P_t^{USD}}{P_{t-1}^{USD}}\right) + \ln\left(\frac{X_t^{USD/RUB}}{X_{t-1}^{USD/RUB}}\right)$$

$$r_t^{RUB} = r_t^{USD} + r_t^{USD/RUB}$$

Systematic Risk Adjustment

Portfolio returns adjusted for systematic risk (beta) relative to market indexes:

German portfolio return in RUB:

$$r_{1t}^{RUB} = \beta_1 y_{1t}^{EUR} + r_t^{EUR/RUB}$$

US portfolio return in RUB:

$$r_{2t}^{RUB} = \beta_2 y_{2t}^{USD} + r_t^{USD/RUB}$$

Aggregate portfolio return:

$$r_t^{RUB} = \omega_1 r_{1t}^{RUB} + \omega_2 r_{2t}^{RUB}$$ $$r_t^{RUB} = \omega_1 \beta_1 y_{1t}^{EUR} + \omega_2 \beta_2 y_{2t}^{USD} + \omega_1 r_t^{EUR/RUB} + \omega_2 r_t^{USD/RUB}$$
Key Insight: This decomposition separates equity risk (β-adjusted index returns) from currency risk (forex returns), allowing independent analysis of each component and their correlation.

EWMA Volatility & Correlation Estimation

Variance Estimation

Exponentially Weighted Moving Average with smoothing parameter λ = 0.94:

EWMA variance recursion:

$$\sigma_t^2 = (1-\lambda) r_{t-1}^2 + \lambda \sigma_{t-1}^2, \quad t = 2, ..., T$$

Initial value:

$$\sigma_1^2 = \frac{1}{T} \sum_{i=1}^{T} r_i^2$$

Interpretation of λ = 0.94

  • Recent observation weight: 6% (1 - λ)
  • Historical volatility weight: 94% (λ)
  • Effect: Emphasizes recent market behavior while maintaining stability
  • Half-life: ~11 trading days (volatility estimate resets about half-way)

Covariance Estimation

Extends EWMA to covariance for correlation estimation:

EWMA covariance recursion:

$$\text{Cov}_t(r_i, r_j) = (1-\lambda) r_{i,t-1} r_{j,t-1} + \lambda \text{Cov}_{t-1}(r_i, r_j)$$

Correlation Dynamics

Correlation coefficient derived from covariance matrix:

Pearson correlation:

$$\rho_{ij,t} = \frac{\text{Cov}_t(r_i, r_j)}{\sigma_{i,t} \sigma_{j,t}}$$
Observation: Correlations tend to increase during crisis periods (Feb 2020, Feb 2022), reducing diversification benefits precisely when needed. This phenomenon is captured by the dynamic EWMA approach.

Value-at-Risk Calculation

1. Parametric (Normal) VaR

1

Assume Normal Distribution

Portfolio returns follow a normal distribution with mean μ and standard deviation σ.

2

Identify Critical Quantile

For 1% significance level (99% confidence), find the z-score from standard normal table:

$$Z_{0.99} = 2.326 \text{ (approximately)}$$
3

Calculate VaR

1-day VaR (percentage):

$$\text{VaR}_{1-day} = \mu - Z_{1-\alpha} \sigma$$

In absolute terms (portfolio value V):

$$\text{VaR}_{1-day, \$} = V \times |\mu - Z_{1-\alpha} \sigma|$$
4

Scale to Multi-Day Horizon

Assuming i.i.d. returns (independent and identically distributed):

10-day VaR:

$$\text{VaR}_{10-day} = \text{VaR}_{1-day} \times \sqrt{10}$$
Assumption: Square-root rule applies when returns are i.i.d. In practice, volatility clustering violates this, making actual multi-day risk more severe than predicted by the square-root rule.

2. Systematic VaR (Multi-Factor)

For portfolios with multiple risk factors, VaR depends on factor volatilities and correlations:

Portfolio variance:

$$\sigma_p^2 = \omega_1^2 \sigma_1^2 + \omega_2^2 \sigma_2^2 + 2\omega_1 \omega_2 \rho_{12} \sigma_1 \sigma_2$$

Portfolio volatility:

$$\sigma_p = \sqrt{\sigma_p^2}$$

Systematic VaR:

$$\text{VaR}_{systematic} = \mu_p - Z_{1-\alpha} \sigma_p$$

3. Historical VaR

1

Sort Historical Returns

Collect all T historical portfolio returns and sort in ascending order: r₍₁₎ ≤ r₍₂₎ ≤ ... ≤ r₍ₜ₎

2

Identify the α-percentile

For 1% significance level, find the 1st percentile (1st smallest return):

$$\text{Index} = \lceil \alpha \times T \rceil$$

For T = 1000 observations: Index = ⌈0.01 × 1000⌉ = 10

3

Extract Historical VaR

The historical VaR is the return at this index position (the actual worst ~1% of historical outcomes).

Comparison of Methodologies

Aspect Parametric VaR Historical VaR
Distribution Assumption Normal (bell curve) Empirical (no assumption)
Tail Risk Capture Good for normal times; misses fat tails Captures real tail behavior
Extreme Events Underestimates (unless λ low) Directly observed
Data Required Less (only mean & variance) More (full distribution)
Computational Speed Very fast Slightly slower
Use Case Regulatory capital, routine risk Validation, stress-testing

Return Calculation

Using log returns (continuous compounding) for statistical properties:

Log return:

$$r_t = \ln\left(\frac{P_t}{P_{t-1}}\right) = \ln(P_t) - \ln(P_{t-1})$$

Advantages of log returns:

  • Statistically well-behaved (approximately normal for short horizons)
  • Additive across time: r[t:t+n] = r_t + r_{t+1} + ... + r_{t+n}
  • Additive across components: r_total = r_equity + r_forex
  • Avoids compounding issues in multi-period analysis
