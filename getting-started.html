Setup & How to Review

File Locations

All files are contained in a single directory:

Market_Risk-main/ ├── Project_Market_Risk_v6.ipynb (Jupyter notebook - complete analysis) ├── 2122_RM_Data.xlsx (Raw data - 5 years of market data) ├── Market_Risk_Report.pdf (Professional report with findings) └── README.md (Documentation)

How to View Each File

1

index.html (This Website)

Open in any web browser. Provides beautiful overview, theory explanations, and navigation. No special software needed.

Time: 15-20 minutes to read completely

2

README.md (Documentation)

Plain text file. Open in any text editor or view on GitHub. Provides detailed explanation of project, methodology, and skills demonstrated.

Time: 20-30 minutes to read completely

3

technical.html (Mathematical Details)

Open in web browser. Contains formulas, derivations, and mathematical framework. Uses MathJax for readable math notation.

Time: 20-30 minutes to review

4

Market_Risk_Report.pdf (Findings)

Professional PDF report. Contains charts, tables, statistical analyses, and conclusions. Open with any PDF reader.

Time: 30-45 minutes to review

5

Project_Market_Risk_v6.ipynb (Code & Analysis)

Jupyter notebook. Open with Jupyter, VS Code, or Google Colab. Contains complete Python code and live output. Run cells to see analysis execute.

Time: 45-90 minutes to review and run

To Run the Jupyter Notebook

Option 1: Anaconda (Recommended)
# Install Anaconda from https://www.anaconda.com # Then in terminal/command prompt: conda install jupyter pandas numpy matplotlib scipy cd Market_Risk-main/ jupyter notebook
Option 2: Google Colab (No Installation)
1. Go to https://colab.research.google.com 2. Select "Upload" tab 3. Upload the .ipynb file 4. Run each cell in sequence 5. Charts and calculations display automatically
Option 3: VS Code
1. Install VS Code and Python extension 2. Install Jupyter: pip install jupyter 3. Open Project_Market_Risk_v6.ipynb 4. Click "Run All" or run cells individually

Frequently Asked Questions

Is this a real project or just practice? ▼

This is a real academic project from a quantitative finance course (based on the PDF naming). However, it demonstrates production-grade analysis that would be used in real financial institutions. The methodology, code quality, and findings are all professional-level and directly applicable to risk management roles.

Can I run the code on my own computer? ▼

Yes! You need Python 3.x with Pandas, NumPy, Matplotlib, and SciPy installed. The easiest way is to use Anaconda or Google Colab (requires no installation). The notebook loads data from an Excel file, so you need that file in the same directory.

How long does the notebook take to run? ▼

The notebook runs very quickly—typically 30-60 seconds on modern hardware. The data is only 5 years of daily observations (~1255 rows), so it's computationally lightweight. You can run individual cells or the whole notebook at once.

Do I need to understand all the math? ▼

No! Different audiences need different depth:

  • HR/Recruiters: Just understand this is rigorous quantitative work
  • Hiring managers: Read the theory section and key concepts
  • Technical teams: Study the formulas and implementation
  • Quants: Deep dive into code and methodology

The learning paths above guide you to the right level of detail.

What if I find a bug or have suggestions? ▼

The code is well-tested (it passes the academic evaluation it was created for). However, if you spot issues:

  1. Check the technical.html for methodology
  2. Review the notebook comments for implementation choices
  3. Refer to the PDF report for findings and validation
  4. Contact to discuss (the original methodology is sound)

Note: The project is not being actively modified; it's a completed, final deliverable.

Can I use this for my own analysis? ▼

Yes! The methodology is generalizable. You can adapt the code to:

  • Different portfolios and asset classes
  • Different time periods and frequencies
  • Different confidence levels (e.g., 95% instead of 99%)
  • Additional risk factors or markets

The structure is modular and well-documented for modification.

How does this compare to industry standards? ▼

This project implements Basel III-compliant risk modeling:

  • ✓ EWMA volatility estimation (industry standard)
  • ✓ Parametric VaR at 99% confidence (regulatory requirement)
  • ✓ Historical VaR for validation (best practice)
  • ✓ Multi-factor risk decomposition (advanced)
  • ✓ Stress testing with real crises (professional)

This would be acceptable for use in real financial institutions (though IT security processes would apply).

Who would hire someone with this skill set? ▼

See the "Career Use" section below. Employers include:

  • Investment banks (Goldman, JP Morgan, Morgan Stanley)
  • Hedge funds and asset managers
  • Risk management consulting (McKinsey, Accenture)
  • Insurance companies and pension funds
  • FinTech companies and startups
  • Central banks and regulators
